Return Policy

Last updated: October 2026

1. Return Window

You may request a return within 7 days of delivery for eligible products.

2. Conditions

  • Product must be unused and in original packaging.
  • Proof of purchase / Order ID is required.
  • Some items (personal care, innerwear, perishable) may not be returnable.

3. How to Request

Go to My Account → Order History, open a delivered order, and click Request Return / Refund.

4. Refunds

Approved refunds are processed to the original payment method or as store credit within 7–10 business days after we receive the item.

5. Contact

Email: support@seimart.com · Help page live chat available.
